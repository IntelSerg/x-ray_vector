# Проектная документация: Система записи на рентгенологические исследования (X-Ray Booking System)

## 1. Исследование и анализ (Бизнес-аналитик и Продакт-менеджер)

### Похожие проекты и референсы
*   **Zocdoc / DocPlanner:** Лидеры рынка онлайн-записи к врачам. Сильные стороны: удобный поиск, напоминания и отзывы.
*   **Calendly:** Эталон интерфейса выбора слотов времени. Простота и отсутствие лишних шагов.
*   **МИС (Медицинские информационные системы):** Часто перегружены и сложны для пациента. Наша цель — упростить этот опыт.

### Основные функции
1.  **Клиентская часть:**
    *   Лендинг с описанием услуг.
    *   Авторизация (Email/Google).
    *   Выбор типа исследования (Флюорография, КТ, МРТ и др.).
    *   Интерактивный календарь с доступными слотами.
    *   Подтверждение записи и отмена.
    *   AI-ассистент для ответов на вопросы (Gemini).
2.  **Админ-панель (для сотрудника):**
    *   Управление расписанием (настройка рабочих часов).
    *   Просмотр списка записей в реальном времени.
    *   Статистика загруженности.
    *   Управление списком исследований.

### Формат реализации
*   **Основной формат:** Progressive Web App (PWA). Это позволяет пользователю заходить через браузер по ссылке, но при этом приложение выглядит и работает как мобильное.
*   **Виджет:** Возможность встраивания формы записи на основной сайт клиники.

## 2. Техническая архитектура (Технический архитектор)

### Стек технологий
*   **Frontend:** React (Vite) + TypeScript.
*   **Styling:** Tailwind CSS (библиотека утилит) + Framer Motion (анимации).
*   **Backend & Database:** Firebase (Firestore для данных, Auth для пользователей).
*   **AI Service:** Google Gemini API (для Q&A формы).
*   **Deployment:** Cloud Run.

### Структура данных (Firestore)
*   `services`: { id, name, duration, price }
*   `bookings`: { id, userId, serviceId, timestamp, status: 'pending' | 'confirmed' | 'cancelled' }
*   `schedule_config`: { dayOfWeek, startTime, endTime, slotDuration }
*   `users`: { uid, email, role: 'client' | 'admin' }

## 3. UX/UI Концепция (UX/UI Дизайнер)

### Визуальный стиль
*   **Цветовая палитра:**
    *   `Medical Blue` (#0EA5E9) — доверие и профессионализм.
    *   `Soft White` (#FFFFFF) — чистота и стерильность.
    *   `Slate Gray` (#64748B) — читаемость текста.
*   **Типографика:** Интер (Inter) — современный, читаемый шрифт.
*   **Принципы:** Минимум полей для ввода, наглядный выбор времени, крупные кнопки.

### User Flow (Путь пользователя)
1.  **Главная:** Краткое описание -> Кнопка "Записаться".
2.  **Авторизация:** Быстрый вход (чтобы сохранить запись).
3.  **Выбор услуги:** Список с иконками и описанием.
4.  **Выбор времени:** Сетка слотов (сгруппированы по датам).
5.  **Финал:** Экран успеха с возможностью добавить в календарь.
